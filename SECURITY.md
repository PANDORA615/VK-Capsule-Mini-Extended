# Безопасность

Не публикуйте `.env`, дампы, ключи, серийные номера и аудиозаписи. При сообщении об ошибке удаляйте секреты. Для чувствительной уязвимости используйте GitHub private vulnerability reporting, если владелец его включил; иначе свяжитесь с владельцем приватно, не публикуя эксплуатируемые детали и ключи.

Сервис слушает localhost. Для LAN обязательны явное разрешение и bearer-токен >=24 символов. Для недоверенной сети нужен HTTPS. Нет shell endpoint и flash writer. Разрешены только HTTP(S) потоки; пользовательские URL доступны владельцу API, поэтому не выдавайте доступ недоверенным пользователям. Не добавляйте административные внутренние URL как радиостанции.

WebSocket принимает одну явно отправленную команду, проверяет Origin и первый auth-пакет. PCM ограничен 30 секундами; HTTP тело ограничено. Идемпотентные действия сохраняются в памяти до 10 минут/256 записей; это не дедупликация через перезагрузку.

Google SDK ошибки нормализуются до кода, без сырого текста запросов/ключей. Настройка debug-логирования сторонних SDK может раскрыть данные; приложение его не включает. Публичная панель не возвращает ключи и полные upstream-конфигурации.
