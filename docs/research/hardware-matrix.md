# Поддержка железа

| Возможность | A113X | RK3308B | Неизвестная плата |
|---|---|---|---|
| Идентификация по предоставленному device-tree | host verified | host verified | определяется как unknown |
| Независимый Linux | описан сторонним автором, у нас unverified | unverified | blocked |
| ALSA, микрофоны, Wi-Fi | hardware_verification_required | hardware_verification_required | hardware_verification_required |
| Передний дисплей и верхние индикаторы | симуляция; физический драйвер не установлен | симуляция; физический драйвер не установлен | симуляция |
| Загрузка после отключения питания | unverified | unverified | blocked |
| Запись flash / восстановление | blocked | blocked | blocked |

**Консоль ≠ root ≠ своё ядро ≠ постоянная установка.** Ни один аппаратный профиль не разрешает запись. Эмулятор приложения не моделирует SoC, загрузчик, NAND, усилитель, GPIO или акустику. QEMU generic ARM также не доказывает совместимость с Капсулой.

Для допуска ревизии нужны: фотографии маркировки платы, пассивный журнал загрузки, device-tree compatible, карта разделов, проверенная резервная копия (включая OOB/ECC по методу NAND), воспроизводимое восстановление, тест ALSA 60 минут, активация при домашнем шуме, Wi-Fi reconnect, свет/кнопки и стабильный голосовой диалог.
