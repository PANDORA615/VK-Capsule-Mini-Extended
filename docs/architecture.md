# Архитектура

FastAPI / Python 3.12 обслуживает меню и API v1. Вопрос поступает в Gemini Live, при сбое — в Flash-Lite с отдельным Piper TTS. Русские команды громкости браузерного ответа и остановки озвучки разбираются локально. При отсутствии моделей возвращается диагностическое сообщение, а не фиктивный ответ.

`capsule/audio.py` сохраняет уровень браузерной озвучки. Физический ALSA-выход относится к Linux-клиенту или внешнему аппаратному агенту. Потоков фонового контента в приложении нет.

`capsule/lights.py` хранит независимые переднюю/верхнюю зоны. Цвет корпуса — отдельная настройка preferences. Эффекты в превью виртуальные; реальные дисплей и ночник подключаются через узкие адаптеры `capsule/bridge.py`. Приём сервером и подтверждение агента различаются.

Голосовой путь: одна явно записанная PCM-фраза → локальный Vosk → командный парсер или AI → WAV-ответ клиенту. Текстовые вопросы не требуют STT. Live-ответ ограничен размером и временем; непрерывная Live-сессия и обученная акустическая активация в Python-клиенте не заявлены.

Меню «Главная / Установка / Свет / Настройки», без CDN и сборщика. Варианты установки — навык, Bluetooth, существующий SSH, Linux-клиент. Внешние инструкции открываются по ссылкам; сайт не запускает прошивку или SSH по нажатию.

По умолчанию localhost. LAN требует длинного bearer-токена и явного разрешения. WebSocket проверяет Origin и первый auth-пакет. HTTP-тела и аудио ограничены; повторные действия дедуплицируются в памяти до 10 минут, 256 записей и 2 МБ. Секреты не возвращаются в статусах. Нет shell endpoint и flash writer.
