# Архитектура

Python 3.12 / FastAPI обслуживает одно приложение и API v1. Простая русская команда идёт в локальный парсер, каталог и независимый mpv-процесс. Неизвестная команда может идти в Gemini Live → Flash-Lite. Радиопоток никогда не является входом AI. При полном отказе AI радио продолжает работать.

`capsule/radio.py` — сериализованное управление mpv JSON IPC, история, атомарное состояние, повторные подключения и URL failover. В режиме simulation используется явный виртуальный backend с инъекцией неисправностей; это не реальное воспроизведение.

`capsule/assistant.py` — circuit breaker с отдельным cooldown каждой модели, Retry-After и диагностикой авторизации. `capsule/providers.py` — официальный Google SDK, ограниченные ответы Live, отдельные Vosk/Piper адаптеры. Аудио отдаётся вызывающему клиенту; браузер играет его локально. Физический Linux-клиент использует ALSA отдельно.

`capsule/lights.py` — отдельные состояния передней и верхней зон, цвет/яркость/эффект, сохранение; только виртуальная периферия до проверки драйверов. Программный mute блокирует приём аудио, но не выдаётся за аппаратное отключение микрофона.

Веб-меню — responsive PWA без внешних CDN и сборщика: интерактивная колонка, радио, свет, настройки. Все элементы меняют серверное состояние. Нет офлайн-кэша API: устаревший успех не показывается при потере связи.

По умолчанию localhost. LAN требует bearer-токена и явного разрешения; WebSocket проверяет Origin и токен. Секреты только в окружении, никогда в статусе и логах. Никакого shell endpoint, flash writer или автоматического UART TX.
