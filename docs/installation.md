# Установка приложения

Если нужно сначала выбрать самый простой путь **для самой колонки**, начните с [сравнения вариантов](simple-assistant-setup.md). Приведённая ниже установка нашего Linux-сервера не является обязательным способом замены заводского ассистента. Фраза активации и способ установки выбираются пользователем.

## 1. Сначала проверьте меню на ПК

Нужны Linux, Python **3.12 или новее**, pip и venv. На Debian/Ubuntu пакет venv должен соответствовать вашей версии Python. Не выполняйте эти команды на штатной прошивке колонки.

```bash
git clone https://github.com/PANDORA615/VK-Capsule-Mini-Extended.git
cd VK-Capsule-Mini-Extended
python3 --version
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
cp .env.example .env
capsulectl doctor
capsulectl serve
```

Адрес: `http://127.0.0.1:8080`. Пока работает терминал, работает приложение. Остановка — Ctrl+C. Повторный запуск — активировать `.venv` и выполнить `capsulectl serve`. Не копируйте `.env.example` поверх уже настроенного `.env`.

В режиме `simulation` виртуальны индикаторы колонки. Можно менять корпус, настраивать свет и проверять сохранение после перезапуска. ИИ не эмулируется: реальный ответ требует ключа, а при его отсутствии сервис сообщает об этом.

## 2. Настройте помощника

Вопросы на главной не требуют специальной команды. Без Google API key сервис показывает честное сообщение о недоступности ответов. Цвет корпуса и настройки света при этом доступны.

Громкость в нашем меню относится к озвучке **в браузере**, а не к ALSA-микшеру физической Капсулы. Динамик колонки работает через отдельно настроенный клиент или аппаратный агент. `CAPSULE_MODE=host` не устанавливает драйверы и не подключает виртуальные LED к железу.

## 3. Откройте меню на телефоне

Вариант без открытия порта в сеть: SSH-туннель до сервера, `ssh -L 8080:127.0.0.1:8080 user@server`, затем localhost на устройстве с туннелем.

Для явного доступа по домашней LAN в `.env` задайте:

```dotenv
CAPSULE_HOST=0.0.0.0
CAPSULE_ALLOW_LAN=true
CAPSULE_TOKEN=длинный_случайный_токен_не_менее_24_символов
```

Сгенерировать случайное значение: `python3 -c 'import secrets; print(secrets.token_urlsafe(32))'`.
Перезапустите сервис. На телефоне откройте `http://IP_ВАШЕГО_СЕРВЕРА:8080`, вкладка «Настройки» → «Токен сервера» → «Подключиться». Страница доступна без токена, но API требует токен. Не пересылайте токен и не публикуйте `.env`.

Для микрофона браузера и установки приложения нужен HTTPS (либо localhost). Подключите свой TLS reverse proxy с проксированием WebSocket и сохранением Host/Origin; браузерное меню → «Установить приложение»/«На экран Домой». Доступность установки зависит от браузера. Манифест есть; офлайн-работа и управление без связи с сервером не заявлены. HTTP допустим только в доверенной домашней сети; для удалённого доступа используйте TLS/туннель.

## 4. Добавьте AI и голос

```bash
pip install -e '.[ai,voice]'
```

Получите собственный Google API key, отдельно установите легальную русскую модель Vosk и Piper (исполняемый `piper`, файл `.onnx` и его `.onnx.json`). Для небольшого устройства рекомендуем размещать STT/TTS на домашнем ПК. В `.env`:

```dotenv
GOOGLE_API_KEY=ваш_ключ
GEMINI_PRIMARY_MODEL=gemini-3.8-live
GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite
GEMINI_ROUTING=auto
VOSK_MODEL_PATH=/absolute/path/to/vosk-model-small-ru
PIPER_MODEL_PATH=/absolute/path/to/ru_voice.onnx
```

Проверьте `capsulectl models`. Наличие модели в списке не доказывает право вызова или оставшуюся квоту. Тарифы: [Google Pricing](https://ai.google.dev/gemini-api/docs/pricing).

После перезапуска текстовый вопрос на главной вызывает Live (ответ озвучивает браузер). HTTP 429/недоступность переводит на Flash-Lite с Piper. Без Piper резервный голосовой путь недоступен. Если обе модели недоступны, приложение сообщает об этом; меню и настройки остаются доступны. Настоящих Google/Piper-вызовов в опубликованном отчёте нет: нет ключа и голосовых моделей.

Для голоса в браузере: «Настройки» → «Записать одну фразу». Отправляется одна запись до 8 секунд, не постоянный микрофон. Локальный Vosk сначала распознаёт текст, затем локальный парсер обрабатывает громкость/остановку озвучки; вопросы направляются AI. Сырые записи не сохраняются. Программный mute блокирует приём аудио; это не аппаратное отключение питания микрофона.

Linux-клиент (на машине с рабочим ALSA и доступом к серверу):

```bash
capsule-client --server http://127.0.0.1:8080 --device default --seconds 6
```

Нажать Enter, сказать команду. Используются `arecord`/`aplay`; API-токен берётся из окружения `CAPSULE_TOKEN`. При необходимости настройте ALSA и права доступа по правилам вашей ОС. Автоматический wake word, barge-in и AEC в этом клиенте не реализованы; опробуйте аппаратный агент из [Gemini-for-Capsula](integrations.md).

## 5. Автозапуск Linux-сервера

Создайте пользовательский systemd unit `~/.config/systemd/user/capsule.service`, заменив `/absolute/project` реальным путём:

```ini
[Unit]
Description=Capsule home application
After=network-online.target

[Service]
WorkingDirectory=/absolute/project
ExecStart=/absolute/project/.venv/bin/capsulectl serve
Restart=on-failure
RestartSec=5
UMask=0077

[Install]
WantedBy=default.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now capsule
journalctl --user -u capsule -f
```

Для работы без пользовательского входа настройте linger по правилам вашей ОС. Это инструкция для Linux-ПК; на Alpine/OpenRC используйте отдельную проверенную службу и подтвердите расход RAM. Не устанавливайте сервер со всем Python/AI-стеком в 256 МБ без измерений.

## 6. Данные, обновление и восстановление

Конфигурация — `.env`; состояние — `state/`: безопасная громкость ответа, цвет корпуса, настройки общения и зон света. Остановите сервис перед резервным копированием этих файлов. При повреждении JSON сервис выдаст понятную ошибку вместо скрытого сброса; восстановите копию или переместите испорченный файл вручную.

Для обновления остановите сервис, сохраните `.env`/`state/`, выполните `git pull --ff-only`, `pip install -e .`, проверки, затем запустите. Версию SDK и зависимости тестовой среды см. в [отчёте](qa/report.md).

## Если не работает

| Симптом | Что проверить |
|---|---|
| Нет ответов ИИ | GOOGLE_API_KEY, доступ к моделям, сеть, фактический режим и коды ошибок |
| Ошибка 401 | Токен сервера в настройках; для Google — ключ и права |
| Голос не распознаётся | VOSK_MODEL_PATH, extra [voice], PCM mono 16 kHz |
| Нет резервного голоса | piper в PATH, ONNX и JSON модели, доступность Flash-Lite |
| Не меняются физические индикаторы | Настроить совместимый агент и явную отправку команды; виртуальные зоны сами не управляют железом |
| На телефоне нет записи | Требуется HTTPS/localhost и разрешение на микрофон |
| Кнопки громкости не меняют динамик Капсулы | Они управляют браузерной озвучкой; физический микшер настраивается в клиенте |
