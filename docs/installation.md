# Установка приложения

## 1. Сначала проверьте меню на ПК

Нужны Linux, Python **3.12 или новее**, pip и venv. На Debian/Ubuntu пакет venv должен соответствовать вашей версии Python. Не выполняйте эти команды на штатной прошивке колонки.

```bash
git clone https://github.com/PANDORA615/VK-Capsule-Mini-Extended.git
cd VK-Capsule-Mini-Extended
python3 --version
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
cp .env.example .env
capsulectl doctor
capsulectl serve
```

Адрес: `http://127.0.0.1:8080`. Пока работает терминал, работает приложение. Остановка — Ctrl+C. Повторный запуск — активировать `.venv` и выполнить `capsulectl serve`. Не копируйте `.env.example` поверх уже настроенного `.env`.

В режиме `simulation` нет реального аудио. Четыре станции — тестовые записи без выдуманных потоковых URL. Можно менять станции, останавливать, регулировать громкость, нажимать на переднюю/верхнюю зоны, менять свет и проверять сохранение после перезапуска.

## 2. Включите настоящее радио на Linux

Установите `mpv` через менеджер пакетов вашего Linux, например `sudo apt install mpv` на Debian/Ubuntu. В `.env`:

```dotenv
CAPSULE_MODE=host
RADIO_MAX_VOLUME=75
RADIO_RESUME_AFTER_REBOOT=true
```

Перезапустите приложение. Вкладка «Радио» → поиск названия → выбрать конкретную станцию. Если каталог недоступен, «Добавить свой поток»: название и прямая разрешённая ссылка HTTP(S). Сохраняйте рабочие станции в избранное. «Включи радио» возобновляет последнюю успешно воспроизводившуюся станцию; до первого успешного запуска выберите станцию вручную.

Звук выводится **на машине с mpv**, а не автоматически в динамик штатной Капсулы и не в телефон. Для звука в колонке нужен установленный на ней совместимый Linux/клиент либо внешний проект из [руководства интеграций](integrations.md). `host` не превращает виртуальные LED в физические.

`RECONNECTING` означает, что декодер перестал продвигаться. Приложение повторяет подключение с задержкой, пробует URL той же станции. Несколько URL можно задать через `POST /api/v1/radio/stations` в поле `urls`. У внешних станций нет гарантии круглосуточной доступности. Название песни не выдумывается; в этой версии track metadata отсутствует.

## 3. Откройте меню на телефоне

Вариант без открытия порта в сеть: SSH-туннель до сервера, `ssh -L 8080:127.0.0.1:8080 user@server`, затем localhost на устройстве с туннелем.

Для явного доступа по домашней LAN в `.env` задайте:

```dotenv
CAPSULE_HOST=0.0.0.0
CAPSULE_ALLOW_LAN=true
CAPSULE_TOKEN=длинный_случайный_токен_не_менее_24_символов
```

Сгенерировать случайное значение: `python3 -c 'import secrets; print(secrets.token_urlsafe(32))'`.
Перезапустите сервис. На телефоне откройте `http://IP_ВАШЕГО_СЕРВЕРА:8080`, вкладка «Настройки» → «Токен сервера» → «Подключиться». Страница доступна без токена, но API требует токен. Не пересылайте токен и не публикуйте `.env`.

Для микрофона браузера и установки приложения нужен HTTPS (либо localhost). Подключите свой TLS reverse proxy с проксированием WebSocket и сохранением Host/Origin; браузерное меню → «Установить приложение»/«На экран Домой». Доступность установки зависит от браузера. Манифест есть; офлайн-работа и управление без связи с сервером не заявлены. HTTP допустим только в доверенной домашней сети; для удалённого доступа используйте TLS/туннель.

## 4. Добавьте AI и голос

```bash
pip install -e '.[ai,voice]'
```

Получите собственный Google API key, отдельно установите легальную русскую модель Vosk и Piper (исполняемый `piper`, файл `.onnx` и его `.onnx.json`). Для небольшого устройства рекомендуем размещать STT/TTS на домашнем ПК. В `.env`:

```dotenv
GOOGLE_API_KEY=ваш_ключ
GEMINI_PRIMARY_MODEL=gemini-3.8-live
GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite
GEMINI_ROUTING=auto
VOSK_MODEL_PATH=/absolute/path/to/vosk-model-small-ru
PIPER_MODEL_PATH=/absolute/path/to/ru_voice.onnx
```

Проверьте `capsulectl models`. Наличие модели в списке не доказывает право вызова или оставшуюся квоту. Тарифы: [Google Pricing](https://ai.google.dev/gemini-api/docs/pricing).

После перезапуска текстовый вопрос на главной вызывает Live (ответ озвучивает браузер). HTTP 429/недоступность переводит на Flash-Lite с Piper. Без Piper резервный голосовой путь недоступен. Если обе модели недоступны, работают локальные команды и радио. Настоящих Google/Piper-вызовов в опубликованном отчёте нет: нет ключа и голосовых моделей.

Для голоса в браузере: «Настройки» → «Записать одну команду». Отправляется одна запись до 8 секунд, не постоянный микрофон. Локальный Vosk сначала распознаёт текст, затем локальный парсер обрабатывает радио/громкость; прочее направляется AI. Сырые записи не сохраняются. Программный mute блокирует приём аудио; это не аппаратное отключение питания микрофона.

Linux-клиент (на машине с рабочим ALSA и доступом к серверу):

```bash
capsule-client --server http://127.0.0.1:8080 --device default --seconds 6
```

Нажать Enter, сказать команду. Используются `arecord`/`aplay`; API-токен берётся из окружения `CAPSULE_TOKEN`. При необходимости настройте ALSA dmix/dsnoop: параллельный mpv и ответ могут конфликтовать без микшера. Автоматический wake word, barge-in и AEC в этом клиенте не реализованы; опробуйте аппаратный агент из [Gemini-for-Capsula](integrations.md).

## 5. Автозапуск Linux-сервера

Создайте пользовательский systemd unit `~/.config/systemd/user/capsule.service`, заменив `/absolute/project` реальным путём:

```ini
[Unit]
Description=Capsule home application
After=network-online.target

[Service]
WorkingDirectory=/absolute/project
ExecStart=/absolute/project/.venv/bin/capsulectl serve
Restart=on-failure
RestartSec=5
UMask=0077

[Install]
WantedBy=default.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now capsule
journalctl --user -u capsule -f
```

Для работы без пользовательского входа настройте linger по правилам вашей ОС. Это инструкция для Linux-ПК; на Alpine/OpenRC используйте отдельную проверенную службу и подтвердите расход RAM. Не устанавливайте сервер со всем Python/AI-стеком в 256 МБ без измерений.

## 6. Данные, обновление и восстановление

Конфигурация — `.env`; состояние — `state/`: станции, избранное, безопасная громкость, последняя успешная станция, настройки зон света. Остановите сервис перед резервным копированием этих файлов. При повреждении JSON сервис выдаст понятную ошибку вместо скрытого сброса; восстановите копию или переместите испорченный файл вручную.

Для обновления остановите сервис, сохраните `.env`/`state/`, выполните `git pull --ff-only`, `pip install -e .`, проверки, затем запустите. Версию SDK и зависимости тестовой среды см. в [отчёте](qa/report.md).

## Если не работает

| Симптом | Что проверить |
|---|---|
| Нет звука в simulation | Это ожидаемо: включить host и установить mpv |
| Нет звука в host | Права аудиогруппы, устройство ALSA/PipeWire, доступность URL, вывод `mpv URL` |
| `RECONNECTING` | Сеть, URL станции, декодер; последняя станция сохраняется только после реального прогресса |
| Ошибка 401 | Токен сервера в настройках приложения; для Google — ключ и права |
| Голос не распознаётся | `VOSK_MODEL_PATH`, extra `[voice]`, формат PCM mono 16 kHz |
| Нет fallback-голоса | `piper` в PATH, ONNX и JSON модели, отдельная квота Flash-Lite |
| Лампочки на колонке не меняются | Виртуальные зоны сами не управляют железом; настройте интеграцию и нажмите отправку |
| «Сервер недоступен» на телефоне | Адрес, firewall, токен, явное LAN-разрешение, HTTPS/туннель |

Суточная проверка настоящего потока: `python scripts/soak.py --station ID --hours 24`. Она занимает реальные 24 часа; результат нельзя заменить быстрым тестом с виртуальными часами.
