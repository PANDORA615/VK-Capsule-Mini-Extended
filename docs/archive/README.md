# Архив исходных материалов

Здесь сохранены исходное ТЗ владельца и результаты проверки внешнего проекта на раннем этапе. Они описывают прежний состав и не являются инструкцией или заявлением возможностей версии 0.2.0. Актуальные функции: ИИ, свет, цвет корпуса и самостоятельный выбор способа установки.
