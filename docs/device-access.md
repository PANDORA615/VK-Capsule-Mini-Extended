# Системный доступ и управление колонкой

## Уровни доступа

| Способ | Возможности | Условия |
|---|---|---|
| Навык на заводской системе | Вопросы и ответы в штатном голосовом интерфейсе | Настроенный навык и backend; это не системный доступ |
| Аппаратный агент | Звук, Bluetooth, индикаторы в пределах объявленных capabilities | Уже работающий совместимый агент и драйверы |
| SSH от обычного пользователя | Терминал с правами пользователя | SSH-сервер, учётная запись и ключ/пароль |
| SSH от root | Администрирование Linux: файлы, службы, пакеты, журналы, драйверы | Существующая учётная запись root и разрешённый вход |
| Независимая ОС | Свой программный стек | Проверенная ревизия, загрузка, backup и recovery |

Цель проекта — подключить ассистента и дать владельцу инструменты управления. Ни браузерная панель, ни API-ключ ИИ не создают root. Консоль, root, своё ядро и постоянная независимая установка — разные результаты. Ограничения загрузчика/OTP/драйверов не снимаются веб-интерфейсом.

## Терминал

В `.env` задайте адрес **своего уже доступного** устройства:

```dotenv
CAPSULE_SSH_HOST=192.168.1.50
CAPSULE_SSH_USER=root
CAPSULE_SSH_PORT=22
CAPSULE_SSH_IDENTITY_FILE=/absolute/path/to/private_key
CAPSULE_SSH_KNOWN_HOSTS_FILE=/absolute/path/to/known_hosts
```

Файлы ключа/known_hosts необязательны, если используются стандартные настройки OpenSSH. Значения — примеры; не публикуйте свои ключи и пароли.

```bash
capsulectl ssh
```

Открывается обычный интерактивный OpenSSH-клиент, а не ограниченный набор команд. Можно управлять системой в рамках прав учётной записи. Проверка ключа сервера включена (`StrictHostKeyChecking=yes`). Если хост ещё не известен, сначала подтвердите его отпечаток через доверенный источник и настройте known_hosts обычным OpenSSH; утилита не добавляет неизвестные ключи автоматически.

Для первичной проверки используйте `id`, `uname -a`, `aplay -l`, `arecord -l`. Наличие SSH не доказывает права root; `id` должен показать uid=0 для root. Реальное подключение к колонке в нашей среде не выполнялось.

## Кнопки веб-панели

Аппаратные команды отправляются в защищённую панель Gemini-for-Capsula, настроенную через `GEMINI_CAPSULA_URL`, `GEMINI_CAPSULA_DEVICE_ID`, `GEMINI_CAPSULA_PANEL_PASSWORD`. Панель сначала ищет именно указанный device ID, проверяет capability команды и ждёт подтверждения агента.

Доступны громче/тише, mute/unmute аудиовыхода, пауза/продолжение/стоп, Bluetooth-сопряжение на 120 секунд и список Bluetooth-устройств. Передний дисплей дополнительно поддерживается через v3rt3p/marusya-server. Нажатие не считается успехом, если агент не подключён.

Mute микрофона в настройках блокирует **приём аудио нашим приложением**. Это не физическое отключение микрофона и не mute аудиовыхода. Громкость ответа браузера, звук радио-процесса и ALSA-микшер аппаратного агента — отдельные выходы.

Произвольные системные команды выполняются владельцем в SSH. Модель ИИ не получает автоматического права исполнять команды root. Совместимость периферии проверяйте по [матрице железа](research/hardware-matrix.md).
