Воспроизведение:

```bash
pip install -e '.[dev,ai]'
pytest -q
ruff check capsule tests scripts
ruff format --check capsule tests scripts
mypy capsule
# В другом терминале запустить capsulectl serve:
CHROMIUM_PATH=/usr/bin/chromium python scripts/check_ui.py
```

Установленные зависимости выдают два предупреждения: переименование pytest CallSpec2 в anyio и deprecation старого httpx TestClient в Starlette. Это не падения тестов; совместимость проверяйте при обновлении.

## Непроверенные возможности

- Реальные вызовы Google, доступность конкретных квот, тарификация и задержка: нужен ключ владельца.
- Реальная русская речь Vosk/Piper: нужны установленные модели и измерения. WAV фикстуры не выдаётся за синтезированный голос.
- Физические ALSA, Wi-Fi, дисплей, LED, кнопки, память/температура на 256 МБ: нужно устройство.
- Наш Python-клиент записывает одну фразу по нажатию; обученная акустическая активация, barge-in и AEC не заявлены. Остановка в браузере отменяет ожидание/озвучку, но не гарантирует отмену уже начавшегося биллинга внешнего API.
- Навык VK, Bluetooth-маршрутизация конкретного приложения и временный SSH-агент описаны как варианты для самостоятельной установки. Опубликованного навыка и универсального root-установщика нет.
- Собственного ядра, Device Tree, прошивочного образа и метода записи flash нет.

Громкость меню относится к ответу в браузере; она не является управлением физическим ALSA-микшером Капсулы. Внешняя команда света различает приём сервером и подтверждение агента; фактическое свечение надо наблюдать отдельно.
