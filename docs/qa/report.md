Команды воспроизведения:

```bash
pip install -e '.[dev,ai]'
# Установить mpv через менеджер пакетов ОС, иначе один decoder test будет skipped.
pytest -q
ruff check capsule tests scripts
ruff format --check capsule tests scripts
mypy capsule
# В другом терминале capsulectl serve, режим simulation:
CHROMIUM_PATH=/usr/bin/chromium python scripts/check_ui.py
```

В pytest среда выдаёт два предупреждения зависимостей: переименование pytest CallSpec2 в anyio и deprecation старого httpx TestClient в установленном Starlette. Они не являются падениями, но версии нужно проверять при обновлении. CI использует Python 3.12 и устанавливает mpv; GitHub Actions проверяется отдельно после публикации.

## Что ещё не подтверждено

- Нет ключа Google: реальные Live/Flash-Lite запросы, доступность квот, тарификация и задержка ответа не измерены.
- Нет установленных голосовых моделей Vosk/Piper: реальная русская акустика, качество STT/TTS и fallback-озвучка не проверены. Фикстура с WAV не выдается за настоящий Piper.
- Нет подключённого штатного `marusya-server` и Gemini-for-Capsula агента: физическое выполнение команд света не наблюдалось. Наш API различает приём сервером и подтверждение агента.
- Нет своей обученной акустической wake-word модели, AEC и полноценного беспрерывного голосового диалога в Python-клиенте. Он записывает одну фразу по нажатию; Live-ответ буферизуется с ограничением размера, не используется как постоянная фоновая сессия.
- HLS/MP3/AAC/ICY поддерживаются возможностями mpv, но в текущей среде проверен только локальный PCM/WAV по HTTP. Публичные станции и их длительная доступность не измерены.
- Нет аппаратной проверки загрузки/микрофонов/ALSA/Wi-Fi/LED/кнопок, температуры, CPU/RAM на 256 МБ и реального 24-часового радио. См. [аппаратную приёмку](../hardware-acceptance.md).
- Нет собственного ядра, Device Tree, flash writer, прошивочного образа или подтверждённого восстановления. Профиль платы — гипотеза по переданному compatible, не разрешение записи.
- Home Assistant, MQTT, Google TTS, серверный Whisper и расписание ночной громкости в этот MVP не включены. Пустые модули/фиктивные кнопки для них не созданы.

Для реальных суток предусмотрен `scripts/soak.py`. Он отказывается работать с симулятором и фиксирует elapsed wall-clock time. Завершённого реального суточного отчёта нет.
