# VK Capsule Mini Extended

Подключение ИИ-ассистента и рабочая панель управления Капсулой: вопросы, звук, Bluetooth, индикаторы и системный доступ через SSH. Без фотографий, макетов корпуса и декоративной модели устройства.

## Возможности

- Gemini Live и резервный Flash-Lite с Piper, текстовые вопросы и запись одной голосовой фразы через Vosk.
- Управление подключённым аппаратным агентом: громкость, mute выхода, пауза/продолжение/стоп, сопряжение Bluetooth и список устройств.
- Настройки переднего дисплея и верхней подсветки через совместимые драйверы/агенты.
- Радио как функция ассистента: команды запуска, смены и остановки станции. Отдельного радиоплеера или карточек станций в интерфейсе нет.
- Обычный системный SSH-терминал: `capsulectl ssh`. При входе под root доступны системные операции с правами этой учётной записи.
- Диагностика, чтение образов, проверка экспортированных резервных копий; универсальная разблокировка/прошивка не заявлена.

**Полный доступ требует уже настроенного SSH/root и работающих драйверов конкретной платы.** Веб-панель и подключение ИИ сами по себе не дают root и не заменяют ОС.

## Запуск панели

Linux, Python 3.12+:

```bash
git clone https://github.com/PANDORA615/VK-Capsule-Mini-Extended.git
cd VK-Capsule-Mini-Extended
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
cp .env.example .env
capsulectl serve
```

Откройте **http://127.0.0.1:8080**. Для ИИ задайте свой ключ в `.env`; для физических команд — адрес, ID устройства и пароль панели совместимого агента. Без подключения статусы не выдаются за успешную работу на колонке.
