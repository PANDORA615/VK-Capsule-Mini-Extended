# Капсула · Дом

Радио, домашний помощник и интерактивное меню света для VK Капсулы Мини.
**Рабочее приложение для Linux и симулятор. Это не готовая прошивка для любой Капсулы.**

![Меню приложения](docs/assets/menu-desktop.png)

Нажмите на передние индикаторы или верхнюю подсветку на изображении колонки: откроются отдельные настройки цвета, яркости и эффектов. На телефоне меню находится снизу; приложение можно добавить на главный экран. Все кнопки связаны с API, настройки сохраняются на сервере.

## Быстрый запуск

Нужны Linux и Python 3.12+. Для первого запуска колонка и ключ Google не нужны.

```bash
git clone https://github.com/PANDORA615/VK-Capsule-Mini-Extended.git
cd VK-Capsule-Mini-Extended
python3 -m venv .venv
. .venv/bin/activate
pip install -e .
cp .env.example .env
capsulectl serve
```

Откройте **http://127.0.0.1:8080**. По умолчанию включена явно обозначенная симуляция: радио и лампочки виртуальные, звука нет. Для настоящего радио установите `mpv`, задайте `CAPSULE_MODE=host` в `.env`, перезапустите сервис и найдите станцию либо добавьте разрешённый HTTP(S)-поток. Звук играет на машине с сервером.

## Что реализовано

- Меню «Главная / Радио / Свет / Настройки», интерактивная колонка, отдельные зоны света и сохранение сценариев.
- Radio Browser, локальный кэш, нечёткий поиск, избранное, mpv, watchdog, переподключение и альтернативные URL.
- Русские команды радио и громкости без LLM, безопасная максимальная громкость, пауза, ducking и восстановление станции.
- Адаптеры Gemini Live и Flash-Lite → Piper, circuit breaker, HTTP 429/401/403, bounded retries и cooldown. Внешние вызовы требуют ключа и моделей.
- Vosk для одной явно записанной команды; Linux ALSA-клиент `capsule-client` с нажатием Enter. Постоянная акустическая активация и AEC ещё не подтверждены.
- Опциональные адаптеры: передний дисплей через `v3rt3p/marusya-server`, верхний ночник через защищённую панель `yawaflua/Gemini-for-Capsula`.
- Только читающие утилиты идентификации/образов, копирование экспортированного backup, dry-run recovery. Записи flash нет.
